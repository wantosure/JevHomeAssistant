# Jev 安卓静默语音助手 · 安装与使用指南

## 一、应用简介

Jev 静默语音助手是一款专为闲置安卓手机打造的 7×24 小时桌面/床头智能中枢：
* **无唤醒词**：随时自然说话，无需“小爱同学”、“Hey Siri”等唤醒口令。
* **不主动接话**：自言自语、看电视、日常闲聊自动进入底部深灰色日志静默忽略，绝不播报语音打扰。
* **动效华丽**：赛博流光声波光环（随分贝能量跳动、Jev 决策旋转、成功翠绿涟漪）、毛玻璃执行卡片、流式涌入字幕。
* **客户端直连**：无需自建云端业务服务，手机本地通过 HTTPS 直接对接 Jev SystemOne 大模型决策中枢。

## 二、快速安装与运行

### 1. 安装 APK
* APK 产物路径：`android-app/app/build/outputs/apk/debug/app-debug.apk`
* 通过 USB 数据线连接手机，运行以下命令即可安装：
  ```bash
  adb install -r app-debug.apk
  ```
  或者将 APK 传输至手机文件管理器中直接点击安装。

### 2. 权限与省电策略设置（关键）
为了实现闲置手机插电 7×24 小时息屏持续监听：
1. **授予权限**：首次打开 App，允许“麦克风录音”与“通知”权限。
2. **电池优化白名单**：进入系统「设置」->「应用管理」->「Jev静默助手」->「省电策略/电池用量」，设置为**无限制 (不优化)**。
3. **允许后台自启与锁屏运行**：在部分机型（小米 MIUI / 华为鸿蒙 / OPPO ColorOS）中，建议将本应用开启“应用自启动”并锁在最近任务栏中。

## 三、功能与界面说明

### 1. 顶部状态栏
* **监听状态胶囊**：点击可随时手动暂停或继续监听。
* **房间指示器**：显示手机当前默认房间（如“📍 客厅”），点击可切换默认房间（主卧、次卧、阳台等）。
* **模式切换徽章**：
  * **OBSERVE (观察模式)**：默认安全模式。所有识别到的指令均进行完整的意图分类与参数校验，并展示执行计划，但不对物理硬件产生副作用。
  * **LIVE (真实模式)**：只有通过真机验证（VERIFIED）的设备方会实际下发物理控制。
* **工具箱图标**：
  * 📱 **设备注册表**：查看从米家极客版转录的真实设备清单、逻辑 ID（如 `h01_living_light_001`）与映射状态。
  * ⏰ **本地闹钟**：查看手机本地由 `AlarmManager` 调度的闹钟列表。
  * ⚙️ **系统设置**：输入和保存用户的 Jev API Key（支持安全存储与重置）。

### 2. 局域网电脑控制端（PC Agent）
在需要被控制的 Windows 电脑上：
1. 双击运行 `pc-agent/start-pc-agent.bat`（默认监听端口 8765）。
2. 在手机处于同一局域网 WiFi 时，对助手说：“把电脑音量调小”、“暂停电脑播放”、“打开浏览器”，电脑即可响应。
