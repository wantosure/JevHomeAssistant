# 静默助手无响应语音文本集 v1

共 1000 条人工编写/模板扩展的中文文本：500 条误触发负例，500 条日常闲聊。全体预期 `ignore`，不执行设备动作、不语音接话。样本当前是合成文本，尚未做人工逐条审校或 TTS 听审；不要把它们当成真实用户录音。

机器可读数据：[no-response-expansion-v1.jsonl](../testdata/no-response-expansion-v1.jsonl)。每行含唯一 `text_id`、`semantic_group`、`text`、预期判定/理由和空动作数组，可并入模拟目录 `sim-home-v1`。

需要中英 TTS 的话，使用共用 ID 的[中英文表格](no-response-bilingual-table.md)或[CSV](../testdata/no-response-bilingual-v1.csv)。

全部设备命令与负例已汇总到[全量测试指令中英表](all-voice-test-cases.md)，通过 ID 与[家庭模拟设备目录](simulated-home-device-catalog.md)中的标注关联。
