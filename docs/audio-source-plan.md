# 语音测试音频获取清单

**后续更新：当前主语料转为中英文语音助手测试集。** 见 [中英文测试集说明](../testdata/bilingual-dataset-README.md)，已下载 CATSLU 中文测试包和 SLURP 英文测试分区，并整理出 1,000 条真人语音。下文保留原 18 句和 ST-CMDS 负例的获取记录，不能将其当作当前全部数据。

对应 [18 条起步样本](../testdata/voice-cases-starter.jsonl)，逐条文件名见 [录音清单](../testdata/recording-manifest.csv)。截至 2026-09-27，这 18 条仍没有逐字对应的音频，`audio_path` 均为 `null`。不能把语义相近的公开录音直接配给原句，否则人工转写与标准答案会错位。另从 ST-CMDS 提取了 [12 条独立负例候选](../testdata/public-stcmds-candidates.csv)，其 WAV 文件在本机 `testdata/audio/public-stcmds/`，须人工回听后才可进入正式评测。

## 本次下载和筛选结果

从 OpenSLR 38 欧洲镜像取得 ST-CMDS 压缩包的前约 1.6 GB（完整包为 8.2 GB），扫描了其中 20530 条转写；**未发现与原 18 句完全相同的转写**。这一结论只覆盖已下载部分，不能推断完整语料中必然没有。找到 22 条提及灯、电脑、电视或空调且配对音频已到手的语句，从中挑选 12 条明显适合测试误触发的候选。音频保持原始 WAV 字节，16 kHz、单声道、16 位 PCM；没有对其剪辑或改写。候选记录及来源 ID 见清单；人工回听及最终标签仍待完成。

## 优先级

1. **18 句精确匹配：自己录。** 用实际闲置安卓手机、实际摆位录制。说话者照清单自然说出原话，保留句首句尾的少量静音；T004/T005/T007 应像平时聊天或复述，不要特意对着助手下命令。原始音频保留，导入测试集时再统一转换为单声道 16 kHz PCM WAV。每句至少由两名说话者各录一次，按人/录制场次分开 dev 与 test。清单中的一个 `Txxx.wav` 只是首录文件名；多说话者追加 `-S02` 等后缀并新建样本 ID，不覆盖原文件。
2. **补充 ASR 和表达方式：AISHELL-2。** [官方介绍](https://www.aishelltech.com/aishell_2)说明包含语音命令、智能家居等领域，并使用手机录制；应先核对授权与下载条款，再检索转写，挑选适合的新语句重新标注。它不能证明原 18 句有逐字对应音频。
3. **补充非指令负例：MagicData-RAMC。** [OpenSLR 123](https://openslr.org/123/)提供手机录制的自然普通话对话与人工转写；约 15 GB，许可为 CC BY-NC-ND 4.0。先按许可核对当前用途，再从中抽取对话段并按新样本标注，不把聊天音频伪装成指令。
4. **补充多说话者普通话：ST-CMDS。** [OpenSLR 38](https://openslr.org/38/)提供手机室内录制、855 名说话者、102600 条转写语音；压缩包约 8.2 GB，许可为 CC BY-NC-ND 4.0。其页面没有给出逐条命令目录，需下载并检索转写后才能确定某句话是否存在。

公开语料的许可证尤其是 NC/ND 条款需要按拟用方式核对；未核实授权前不将语料打进 App 或公开再分发。现阶段无须下载 8–15 GB 语料包来补这 18 句，自己录更快，而且更能反映实际手机、房间和说话人的误触发率。

## 录音和导入规则

- 录制时暂时禁用实际设备执行，仅做观察模式。先录清晰近场版，再录手机正常放置的远场版；后者用新样本 ID 和独立标签。
- 闹钟两句按清单念原文，评测基准时间仍使用 JSONL 里的固定时间，不由音频文件时间推断。
- 录音者不必刻意强调“开/关”“零/一百五”等字，否则会低估自然说话时的错误率。
- 将有效 WAV 放在 `testdata/audio/`，按清单文件名保存。人工回听核对逐字稿后，才把对应 JSONL 行的 `audio_path` 改成相对路径，例如 `audio/T001.wav`。
- 对公开语料新建 ID 并保留 `source_dataset`、原始文件 ID、许可证、原始转写；不能修改本表原句来迁就现成录音。
- 交付前检查声道、采样率、时长、是否削波，并人工听一遍。合成语音可用于接口冒烟测试，不能充当真人远场与误触发评测。
